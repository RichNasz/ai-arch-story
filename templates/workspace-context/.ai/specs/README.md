# Workspace Agent Context

Read this file first. These specifications describe how an agent works in this
user-owned workspace; they do not describe how to develop AI Arch Story.

Read the relevant specification before changing content:

- `workspace-purpose.md` for ownership and workflow boundaries
- `workspace-structure.md` for file locations and shared assets
- `diagram-schema.md` for valid diagram definitions
- `visual-design.md` and `flow-visualization.md` for presentation choices
- `custom-types.md` for reusable node and SVG shapes
- `agent-workflow.md` for safe collaborative editing

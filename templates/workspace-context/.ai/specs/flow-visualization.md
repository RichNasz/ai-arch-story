# Flow Visualization

Flows explain how data or work moves through an architecture. Create them when
the user describes a sequence, request path, event path, or processing story.
Each flow references an ordered path of existing edges. Use a concise label,
optional narrative description, and a suitable animation: `particle` for
discrete items, `pulse` for sequential processing, or `highlight` for static
emphasis.

Do not invent flows when the user describes only a structural relationship.
